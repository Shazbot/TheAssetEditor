# PackOptimizerBench

Headless runner for `PackTextureAtlasBatchService.Process`, to measure the batch tool's runtime and to check that an optimisation leaves its output unchanged.

Run (Release, from the repo root):

    dotnet build Tools\PackOptimizerBench -c Release
    dotnet Tools\PackOptimizerBench\bin\Release\net10.0-windows\PackOptimizerBench.dll --tag run1

It loads the WH3 packs from `K:\SteamLibrary\steamapps\common\Total War WARHAMMER III\data` and the source pack `K:\wh3mods\albion\!ak_teb3.pack` (read-only), runs `Process` with the last real run's options (atlasing off; cross-rigid, merge, geometry, downscale, repack, compaction, drop unread alpha on), and writes `bench_output.pack`, the report, `fingerprint.txt` (SHA-256 of every output file plus the report without timing lines) and `wall_time.txt` to `K:\projects\assedfork-bench\<tag>\`. Options: `--source`, `--game-dir`, `--out`, `--tag`, `--report-diagnostics true|false` (default true; false skips the report-only audits), `--prune-dead-files true|false` (default false; true removes unreferenced leftovers of the source pack), `--switch-opaque-alpha true|false` (default false; true moves opaque alpha-tested character materials to the non-alpha twin shader). Diff two `fingerprint.txt` files to check a change. Cross-rigid experiments (output changes unless left at defaults): `--cross-rigid-merges false`, `--compress-rigid-models true`, `--xr-physical-mib-per-draw N` (default 4), `--xr-resident-mib-per-draw N` (0.5), `--xr-growth-cap-mib N` (256), `--xr-min-single-vmd-draws N` (0.02), `--xr-max-drawcall-increase N|inf` (default 0 expected draws; `inf` disables the gate), `--xr-drawcall-price X|inf` (price mode: maximizes instance saving minus X per expected distinct draw instead of a hard cap; mutually exclusive with `--xr-max-drawcall-increase`; `inf` equals cap 0 without portfolio search; skips the portfolio search), `--xr-drawcall-frontier true` (adds the removal frontier table to the report). Shared texture repack gates (output changes unless left at defaults): `--repack-min-set-kib N` (default 128; a set must save this much, estimated and actual), `--repack-min-group-kib N` (default 128; per layout group).

With a finite `--xr-max-drawcall-increase`, cross-rigid selection evaluates up to three deterministic rounds of portfolio proposals, with a global limit of 192 actual trials and at most 64 trials per round. It can add unselected payloads, replace conflicts, combine independent improvements, and try alternate source-rigid completion cohorts. Each proposal is replayed through the existing rewrite-conflict and geometry/residency constraints, and is accepted only when its modeled expected draw-call increase is within the configured limit. The report includes incumbent and best instance-draw savings, global and per-round budgets, rounds, accepted improvements, and whether unique proposals remained when the global budget was exhausted. Setting the limit to `inf` skips the stronger search and preserves the existing selection.
